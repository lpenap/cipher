# Cipher
Java AES/RSA Cipher Application to manage encrypted text.

## Requirements
* Java 21
* Gradle (provided by wrapper) 8.14.2

## Technology overview
* Java 21
* Gradle 8.14.2
* Spring Boot 3.5.0 (headless)
* Java Swing User Interface
* JPA + Hibernate ORM
* H2 Database
* Lombok
* slf4j for logging
* JUnit + mockito for testing
* Travis CI

## Run (Development Only)
* Clone this repo
* Execute
```bash
./gradlew bootRun
```
